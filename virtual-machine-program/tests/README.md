# VM Verification

Tests should cover:

1. 1024-bit addition, subtraction, multiplication and division.
2. Bitwise and shift operations.
3. Vector and matrix operations.
4. Math Engine bridge operation IDs.
5. Quantum gate correctness.
6. State-vector normalization.
7. Measurement probability conservation.
8. Deterministic seeded simulation tests.
9. CPU/GPU/quantum interoperability.
10. Regression tests against repository mathematical datasets.

The first implementation milestone should require classical smoke tests to pass before enabling larger quantum workloads.
