# Roadmap
Current: native dashboard, C++23 VM library, 1024-bit arithmetic, vector operations, virtual memory, ISA decoding, quantum state vectors/gates, Math Engine bridge, regression tests, Windows CI.
Next: live dashboard bindings, full instruction executor, assembler binary output, virtual BIOS/devices, debugger, profiler, persistent VM state, GPU rendering pipeline, complete quantum measurement collapse, additional quantum gates, and SystemVerilog reference RTL.
Hardware path: future work can map validated components to FPGA/ASIC RTL or connect the quantum layer to an external backend.
