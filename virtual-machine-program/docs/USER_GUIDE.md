# Virtual 1024 Computer User Guide
1. Build with Visual Studio 2022 x64 and CMake.
2. Run CTest.
3. Launch vm1024-dashboard.exe.
4. Use the dashboard as the control surface; the CLI remains available for headless validation.
5. Load V1024-QISA examples through the assembler.
The CPU/GPU/QPU panels describe simulated devices. Math Engine operation IDs connect the VM to the repository mathematical registry.
