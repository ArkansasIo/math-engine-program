# Components
- CPU1024: 1024-bit integer representation and arithmetic.
- GPU1024: vector operations and baseline dot product.
- Memory: bounds-checked virtual byte memory.
- ISA/Decoder: V1024-QISA opcode model.
- Quantum CPU: state-vector register and core gates.
- Quantum measurement: probability calculation.
- Math Bridge: stable operation identifiers for the repository Math Engine.
- CLI/tests: executable smoke path and regression checks.
- CI/package: reproducible Windows x64 build and release archive.
