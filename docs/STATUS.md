# Development status

Implemented in this initial source commit:
- C++23/CMake build foundation
- Interactive CLI
- Integer arithmetic and number classification
- Primality, GCD, LCM, and prime-factorization utilities
- Basic mathematics knowledge graph with path and child queries
- Smoke/unit tests and starter Prolog rules

Planned/not yet implemented:
- Complete symbolic algebra and calculus
- Arbitrary-precision numeric backend
- Runtime Lua and Prolog integration
- Native graphical user interface and production 2D/3D rendering
- HTTP server for the OpenAPI contract
- Networked, signed update and patch installation

This is a development scaffold; do not treat placeholder or planned subsystems as production-ready.
